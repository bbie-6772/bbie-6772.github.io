## 블로그 관리

- 현재 블로그를 작성할 때 보는 사람의 입장이 아닌, 그냥 되는대로 작성하는 것 같다는 지적을 받게 되었다.

> 그래서 작성 방식에 대한 개선점을 찾아보았다.  
  
### 디버깅 접근성 개선

- 블로그에 글을 작성할 때, VScode의 마크다운 화면만 확인하기 때문에 블로그의 실제 페이지를 확인해가며 수정하기 어렵다!

> Github Page가 아닌 로컬에서 실시간 빌드 하는 방법을 찾아 화면을 확인하며 수정해보자!

1. 로컬에서 Github Pages에서 쓰는 **Jekyll(블로그 생성 프로그램)**을 사용하기 위해 설치를 진행한다!

2. 설치를 진행하기 위해 **Ruby(동적 객체 지향 프로그래밍 언어)를 먼저 설치**해야 한다..  
(Jekyll은 Ruby로 작성되어 있기 때문이다!)

3. Ruby 설치 후 명령 프롬프트를 실행하여 아래의 명령어를 입력 해주면 Jekyll 설치가 마무리 된다!

    ```bash
    gem install jekyll bundler
    ```

4. 실행시킬 프로젝트(폴더)의 오류를 줄이기 위해 Bundler를 설치해준다!(대부분의 최신버전 Ruby 설치 시 포함되어있음)

5. Git bash에서 실행할 Jekyll 폴더로 들어가 아래의 명령어들을 입력해준다!

    ```bash
    # 폴더에 번들 설치
    bundle install
    # 번들을 이용해 jekyll 실행
    bundle exec jekyll serve
    ```

6. 이후 localhost:4000 에 들어가면 정상적으로 실행이 된다!

    ![로컬블로그](https://github.com/user-attachments/assets/312c02c0-22e7-4296-8ae3-fdd4fe24a548)

7. 마지막으로 명령어 입력없이 쉽게 jekyll을 실행 해주기 위해 **jekyll run(VScode 확장 프로그램)** 을 설치 해준다!

    ![jekyll-run](https://github.com/user-attachments/assets/e4ecb3fc-b5af-4d2c-b189-49234270bacd)

    - 아래의 버튼을 눌러 쉽게 실행하고 재시작/멈춤 을 제어할 수 있다!

### 시간 배분 개선

- 과제 및 공부를 하고난 후, 정리를 하는 시간이 부족하다고 생각을 많이 했다!

1. 과제 및 공부 진행중 중요하다 생각되는 부분/단어를 적어두자

2. 일에 우선순위를 정하여 블로그 정리 하는 시간을 소홀히 하지 않도록 노력해야겠다.
