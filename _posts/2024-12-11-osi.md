## OSI 7계층

- OSI[Open System Interconnection model]는 네트워크 통신 방법을 개념적으로 설명한 국제 표준이다.

- OSI 7계층 덕분에 통신 주체(시스템/언어/기기)가 달라져도 서로 통신이 가능한 것 이었다!

- 캡슐화 (7계층 -> 1계층)

    송신자의 PayLoad(내용)는 계층을 거칠 때마다 PayLoad(내용)의 정보를 알려주는 Header/Trailer(명찰)을 달아주며 다음 계층으로 이동한다.

- 역캡슐화 (1계층 -> 7계층)

    수신받은 Packet은 계층을 거칠 때마다 Header/Trailer(명찰)를 지워가며 다음 계층으로 이동한다

- OSI 7계층

| OSI 계층 | 대표 기능 |
| --- | --- |
| 1계층/물리계층 | 데이터 전달 : 네트워크 장치의 전기적, 기계적 특성을 이용해 데이터를 전송 |
| 2계층/데이터링크 계층 | 주소 할당/오류 감지 : 데이터가 오류 없이 전달되도록 전송 단위를 관리하며 물리 계층의 신호를 데이터로 변환 |
| 3계층/네트워크 계층 | 여러 개의 노드를 거칠 때마다 경로를 찾아주는 역할을 하는 계층,  인터넷에서는 인터넷 프로토콜 v4(IPv4) 및 IPv6가 주 네트워크 계층 프로토콜로 사용됨 |
| 4계층/전송 계층| 신뢰성/흐름 제어/다중화 : 서로 다른 네트워크 간 통신 흐름을 관리하며 오류를 검출 및 복구하여 신뢰성을 체크하며 데이터를 작은 조각(패킷)으로 나눠 보냄 |
| 5계층/세션 계층| 인증,권한 부여 : 통신 주체 간 연결의 시작,유지 및 종료하는 기능을 담당 |
| 6계층/표현 계층| 암호화/압축 : 응용 프로그램이 데이터를 알맞게 표현할 수 있도록 변환 해주는 담당 |
| 7계층/응용 계층| 클라이언트의 요청 / 서버의 응답 의 형태를 지정해주는 계층 (표준화된 통신 방법(프로토콜)과 관련) |

### 물리 계층

- OSI 7계층의 가장 하위에 위치한 1계층으로 하드웨어를 의미함

- 아날로그 신호인 전파를 0과 1의 디지털 데이터(bit)로 변환(반대로도)하는 역할
