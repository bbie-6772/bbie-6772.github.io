## 프로젝트 마무리

- [프로젝트](https://github.com/bbie-6772/THESIMPLETOWERDEFENSE) 가 마무리 되었다!

- 여러 팀들의 프로젝트를 보며 느낀 점이 생겼다

### 자체 피드백

#### Keep

- 프로젝트에 책임감을 가지고 휴일임에도 나와서 다같이 프로젝트 마무리를 한 점은 뿌듯했다.

- 중간마다 각자 작업 진행도를 파악하며 업무를 재분배한 점은 좋았다!

#### Problem / Try

- 클라이언트 요청 -> 서버 응답 처럼 동기적 실행이 필요한 통신은 웹소켓 통신보다 API 통신을 이용해 리소스를 줄였으면 좋았을 것 같다.

- 파일 구조 설계 시, 각 팀원분들의 설계 방식을 공유하여 규칙들을 미리 정해놓았으면 좋았었을 것 같다.

  - 특히 구현 중 기능이 연관된 팀원 분들끼리는 협의가 필요한 부분을 상의했으면 좋았었을 것 같다..

- 다들 처음 해보는 유형이었기에 전체적 구조가 중간중간 변경되었는데,  
프로젝트 중간 병합 과정에서 구조에 맞춘 리팩토링이나 추가 구현 방식을 명확하게 정했었으면 좋았었을 것 같다

- 트러블 슈팅하는 과정에서 문제 발견 시점, 가설, 문제 해결 시도 구역을 나눠  
과정마다 화면 캡쳐나 한 줄씩 적어두는 습관이 필요할 것 같다.

## 한줄 평 + 개선점

- 프로젝트 중반쯤 부터 병합과 오류 해결만 신경써 전체적 구조나 코드 리뷰를 못했던 것이 아쉬웠다  
( 수용력이 부족한 것 같아 최대한 타협하지 않는 습관을 들여야겠다 )
