## 지식창고

### 스탠다드

#### OSI 7계층

- OSI[Open System Interconnection model] 는 네트워크 통신 방법을 개념적으로 설명한 국제 표준이다.

- 이러한 표준을 정하여 통신 주체(시스템/언어/기기)가 달라져도 서로 통신가능하게 만들어 준다.

- 캡슐화 (7계층 -> 1계층)

    송신자의 PayLoad(데이터)는 계층을 거칠 때마다 PayLoad(내용)을 알려주는 Header/Trailer(명찰)을 달아주며 다음 계층으로 이동한다.

- 역캡슐화 (1계층 -> 7계층)

    수신받은 Packet은 계층을 거칠 때마다 Header/Trailer(명찰)를 지워가며 다음 계층으로 이동한다

![캡슐](https://lh6.googleusercontent.com/proxy/L6ExjpKpfNiSD73KMyJhIx_5HnejcJn8l-sNNoznLbkQfhWQqUWqnnKZxNvX4mwucxaylLzRTnCxzxO0dUP9Tj82Lb9KbD8)

- OSI 7계층

| OSI 계층 | 대표 기능 |
| --- | --- |
| 1계층/물리계층 | 데이터 전달 : 네트워크 장치의 전기적, 기계적 특성을 이용해 데이터를 전송 |
| 2계층/데이터링크 계층 | 주소 할당/오류 감지 : 데이터가 오류 없이 전달되도록 전송 단위를 관리하며 물리 계층의 신호를 데이터로 변환 |
| 3계층/네트워크 계층 | 여러 개의 노드를 거칠 때마다 경로를 찾아주는 역할을 하는 계층,  인터넷에서는 인터넷 프로토콜 v4(IPv4) 및 IPv6가 주 네트워크 계층 프로토콜로 사용됨 |
| 4계층/전송 계층| 신뢰성/흐름 제어/다중화 : 서로 다른 네트워크 간 통신 흐름을 관리하며 오류를 검출 및 복구하여 신뢰성을 체크하며 데이터를 작은 조각(패킷)으로 나눠 보냄 |
| 5계층/세션 계층| 인증,권한 부여 : 통신 주체 간 연결의 시작,유지 및 종료하는 기능을 담당 |
| 6계층/표현 계층| 암호화/압축 : 응용 프로그램이 데이터를 알맞게 표현할 수 있도록 변환 해주는 담당 |
| 7계층/응용 계층| 클라이언트의 요청 / 서버의 응답 의 형태를 지정해주는 계층 (표준화된 통신 방법(프로토콜)과 관련) |

#### 물리 계층

- OSI 7계층의 가장 하위에 위치한 1계층으로 하드웨어를 의미함

- 아날로그 신호인 전파를 0과 1의 디지털 데이터(bit)로 변환(반대로도)하는 역할

### 알고리즘 코드 카타

#### 옹알이 (2)

- 문제  

머쓱이는 태어난 지 11개월 된 조카를 돌보고 있습니다.  
조카는 아직 "aya", "ye", "woo", "ma" 네 가지 발음과 네 가지 발음을 조합해서 만들 수 있는 발음밖에 하지 못하고 연속해서 같은 발음을 하는 것을 어려워합니다.  
문자열 배열 babbling이 매개변수로 주어질 때, 머쓱이의 조카가 발음할 수 있는 단어의 개수를 return하도록 solution 함수를 완성해주세요.

- 조건

  - 1 ≤ babbling의 길이 ≤ 100
  
  - 1 ≤ babbling[i]의 길이 ≤ 30

  - 문자열은 알파벳 소문자로만 이루어져 있습니다.

```jsx
function solution(babbling) {
    let answer = 0;
    //옹알이 저장
    const word = ["aya","ye","woo","ma"]
    
    answer = babbling.reduce((acc,cur) => {
        // 값이 옹알이에 있는 것과 같으면 바로 +1 
        if (cur === word.find((val) => val === cur)) return acc + 1
        let double = cur
        for (let i = 0;i < word.length;i++) {
            // replace에서 전역으로 검사하기위해 RegExp 사용
            const w = new RegExp(word[i], "g");
            double = double.replace(w,i)
            // 만약 같은 숫자가 이어질경우 옹알이가 불가능하기에 for을 빠져나옴
            if (double.includes(`${i}${i}`)) break
            // double이 모두 숫자로 채워지면 가능하다는 말이기에 +1 
            if (/^[0-9]*$/.test(double)) return acc + 1
        }
        return acc
    },0)
    
    return answer;
}
// 근데 나중에 보니까 replaceAll 이라는 좋은 구문이 있더라
```

- 다른코드 분석

```jsx
function solution(babbling) {
    //옹알이를 정규식을 이용해 반복 여부 확인
    const regexp1 = /(aya|ye|woo|ma)\1+/;
    // 정규식을 이용해 단어가 옹알이로 이뤄졌는지 확인
    const regexp2 = /^(aya|ye|woo|ma)+$/;

    return babbling.reduce((ans, word) => (
        // 반복되지 않고 옹알이로 단어가 나눠지면 +1 아닐경우 그대로
        !regexp1.test(word) && regexp2.test(word) ? ++ans : ans
    ), 0);
}
```
