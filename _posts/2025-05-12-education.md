### 아티클 정리

- 주제 : [스타트업 인턴해 본 썰 푼다: 인턴이 이런 것까지 할 수 있다고?!](https://blog.career.spartacodingclub.kr/Intern)

- 한줄 요약 : 인생에 여러 갈래의 길이 있지만 환경과 사고방식에 따라 누구나 성장 할 수 있다.

#### 요약

- 스파르타 코딩클럽 인턴
  - 인턴도 A부터 Z까지 **업무를 책임지고 리드**할 수 있는 ‘**진짜’ 경험**을 할 수 있는 곳
  - **성장하기 좋은** 팀스파르타의 **빠르고, 와우하며, 진정성 있는 자세**
  - **내용을 명확하지만 부드럽게** 전달해 **불필요한 감정을 줄여**주고 팀원이 한 사람으로 **존중**받는 **소통 문화**
  - 질문을 두려워하지 않는 **모름을 인정하는 태도**를 멋있다고 평가하는 **성장하는 문화**

#### 느낀 점

처음에 아티클을 읽었을 때는 ‘팀스파르타 인턴’분들이 이렇게 많은 경험을 했구나 라고만 생각하게 되었다.
그러다 ’이 경험들이 현재 내가 배우고 있는 과정과 어떠한 연관이 있지?’ 라는 것에 초점을 두면서 다시 읽어보자 **인턴분들의 성장의 비결**인 **실무에 녹아있는** **팀스파르타만의 작업 방식과 회사 문화**를 발견하게 되었다.

짧게는 2달 길게는 1년까지의 인턴 기간 속 주요 경험들을 보면서 건강하고 와우한 회사의 핵심 가치가 돋보였다. 인사담당부터 시작해서 마케팅 및 개발자까지 **다양한 직군의 인턴**이 **하나의 회사**에서 **모두 빠르게 성장한** 결과가 인상 깊었다.

### 데이터 리터러시(Data Literacy)

- 데이터 리터러시란 데이터를 읽고 이해한 바탕으로 분석 결과를 전달하는 능력을 의미한다!
  - 데이터를 **읽고 해석**하는 능력
  - 데이터를 **분석 및 시각화**하는 기술
  - 데이터를 **평가**하고 **활용**하는 사고방식

- 데이터는 글, 수치, 이미지 등 다양한 형태로 존재하고, 이를 이해해 활용할 수 있다면 더 신뢰할 수 있는 결과물을 만들어 낼 수 있다!

#### 데이터의 중요성

- **효과적인 의사결정**
  - 데이터를 기반으로 한 판단은 **신뢰성과 정확성**을 높여줌
  - 수강생들의 학습 데이터를 분석해 **맞춤형 학습 계획**을 수립
  - 수강생의 참여도와 만족도를 데이터로 평가하여 **프로그램의 개선점을 도출**

- **문제 해결 역량 강화**
  - 데이터 분석을 통해 **복잡한 문제를 체계적으로 해결**할 수 있음
  - 프로그램 운영 과정에서 발생하는 문제를 데이터 기반으로 **신속하고 체계적으로 해결**할 수 있음

- **학습 결과 가치 창출**
  - 데이터를 활용해 **취업 데이터에 긍정적인 변화**를 만들 수 있음
  - 학습 성과와 캠프의 긍정적 영향을 데이터로 입증하여 **학습 가치를 더욱 명확히 전달**할 수 있음

#### 데이터의 종류

- **정형 데이터** : 구조화된 형태로 데이터베이스나 엑셀에서 쉽게 관리할 수 있는 데이터

- **비정형 데이터** : 고정된 형식이 없으며 텍스트, 이미지, 오디오, 비디오 등 다양한 형태로 존재하는 데이터

- **정량 데이터** : 숫자로 측정 가능하며 분석 및 시각화하기 쉬운 데이터

- **정성 데이터** : 숫자로 표현하기 어려운 감정, 경험, 의견 등의 데이터를 포함

- **내부 데이터** : 운영진과 내부 조직만 확인하는 데이터

- **오픈소스 데이터** : 외부에서 공개된 데이터로, 누구나 접근 가능한 자료

#### 데이터의 활용성

- **협업 시 의사결정의 근거** : 데이터에 기반한 협업은 운영 간 신뢰를 높이고, 효율적인 업무 분담을 가능하게 함

- **비지니스 전략 수립** : 전략적 의사 결정을 통해 캠프의 성과를 극대화하고, 지속 가능한 성장 동력을 확보가능

- **KPI 달성을 위한 Action item 도출** : 데이터를 기반으로 한 Action Item은 실질적이고 실행 가능한 목표를 제공하며, 성과를 체계적으로 관리할 수 있음

#### 데이터분석 과정

1. **데이터 수집** : 분석의 첫 단계로 목적에 필요한 데이터를 수집하는 과정

2. **데이터 전처리** : 수집한 데이터를 분석 가능한 상태로 정리 및 정제하는 과정
    - 카테고라이징 : 데이터를 주요 범주로 분류하는 작업
    - 결측값 처리 : 누락된 데이터를 보완또는 제거하여 정확성을 높이는 작업
    - 분석 목적 : 분석 목표에 따라 데이터를 구조화하는 작업

3. **데이터 분석** : 전처리된 데이터를 기반으로 패턴과 인사이트를 얻는 과정
    - 패턴 찾기 : 데이터 간 상관관계를 파악하는 작업
    - 문제 정의 : 데이터를 통해 일어날 문제 현상을 정의

4. **결론 도출** : (시각화, 문제정의)분석 결과를 바탕으로 실행 가능한 결론을 생각하는 과정
    - 시각화: 차트, 그래프, 대시보드 등을 활용하여 분석 결과를 쉽게 이해할 수 있도록 시각적으로 표현
    - 문제 정의 대응 방안: 낮은 만족도의 원인을 해결할 수 있는 구체적 실행 계획 제안
