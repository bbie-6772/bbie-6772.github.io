### 현 상황

카드 수집에 이용되는 절차를 자동화하기 위해 Claude AI Skills 에 명세서를 작성하게 되었다.
기존의 디렉토리 구조에서 Claude Code를 연동시킨 후 Github CLI를 설치하여 커밋과 풀리퀘도 가능하도록 환경을 설정해주었다.

#### AI Skill

AI 에이전트에게 특정 분야의 전문 지식, 업무 절차(워크플로우), 그리고 실행 도구(스크립트 등)를 패키지 형태로 장착시켜 전문가처럼 일하게 만드는 맞춤형 기능

- 이미 만들어진 파일 구조에 맞춘 규칙들과 양식들을 이용해 작성진행 (대부분 설명으로된 MD 파일)

#### 프로세스 구상

이제 RAG 자료들을 통해 기획 AI가 사용자의 아이디+@ 를 기획할 수 있게 되었다.
하지만 이를 토대로 개발자 AI(및 QA AI)에게 게임 구조와 개발 설계도를 어떻게 전달해야 효율적으로 진행되는지 고민을 하며 어떻게 프로세스를 나누어야할지 고민을 해야한다.

- Unity MCP 에게 전권을 주며 게임 구조를 한번에 던지는게 과연 효율적일까?

- 개발자와 QA가 불가능한 영역을 기획자 AI가 어떻게 구분하고 피드백을 받을 수 있을까?

- [ 기획 > 게임 구조 파악 > 프롬프트/자료 작성 > 개발 > QA > 기획 AI 피드백 > 재실행 ]구조로 진행되면 어떨까

고민은 많았지만, 사실 이에 대해 토론할 수 있는 영역은 같은 초보 개발자인 팀원분들과 AI뿐이기에 멘토링을 신청하며 궁금증을 해결해볼까 한다 

## 한줄 평

- Claude Code 와 같이써서 처음으로 세션 토큰사용 제한을 받아본게 신기했다.
