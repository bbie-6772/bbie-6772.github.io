### 회의내용

간단한 자기소개 이후 고정 미팅을 정하는 시간을 보냈다. 기본적인 그라운드 룰까지 정하고 마무리 했다.  
( 고정 미팅 시간 : 매주 수요일 14:00 ~ 15:00 )  
  
추가로 아이디어(방향성) 채택을 위해 팀원분들끼리 중간중간 추가 의견을 내고, 이를 PM님이 취합하여 화요일에 투표하기로 했다.

#### 개발자 회의

- Node.js / Java / Kotlin 의 학습곡선 및 메인 언어 개발자분 비율을 생각해 Kotlin을 채택하기로 하였다

- [Riido](https://www.riido.io/) 협업 플랫폼을 이용해 자기 할당량을 주체적으로 관리(미정)

- 전체 개발 관리는 플랫폼은 깃허브 통일로 진행하기 ( 플랫폼이 많아질수록 접근성이 낮아짐 )

- 이전 기수 참여자분의 경험을 토대로 에자일(Agile) 방법론을 채택하는 방향으로 진행

- CI / CD 깃헙 액션 및 로깅 서버(Grafana Loki)를 처음부터 구축하며 시작

- [지속 성장 가능한 코드](https://geminikims.medium.com/%EC%A7%80%EC%86%8D-%EC%84%B1%EC%9E%A5-%EA%B0%80%EB%8A%A5%ED%95%9C-%EC%86%8C%ED%94%84%ED%8A%B8%EC%9B%A8%EC%96%B4%EB%A5%BC-%EB%A7%8C%EB%93%A4%EC%96%B4%EA%B0%80%EB%8A%94-%EB%B0%A9%EB%B2%95-97844c5dab63) 의 Layer 규칙을 통해 느슨한 결합을 유지하여 유지보수성 높이기
